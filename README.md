Netflix Power BI Data Analysis

Project Overview

This project was developed as part of a Data Analysis Internship using Microsoft Power BI.

The project analyzes Netflix content to provide insights into content distribution, geographical markets, growth trends, audience ratings, and content categories.

Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization
- GitHub

Completed Tasks

Task 1 - Data Preparation & Power BI Setup
- Imported and cleaned the Netflix dataset using Power Query.
- Handled missing values, duplicates, and data types.
- Created supporting tables for country and audience/category analysis.
- Built relationships between tables.

Task 2 - Netflix Content Overview
Created an overview dashboard containing:
- Total Content
- Total Movies
- Total TV Shows
- Top 10 Countries
- Movies vs TV Shows
- Content Released by Year
- Interactive filters

Task 3 - Global Content Insights
Analyzed Netflix content distribution across countries using:
- Global map visualization
- Total countries
- Top country
- Top 10 countries by content
- Movies vs TV Shows by country
- Market insights
- Interactive slicers

Task 4 - Content Growth & Trend Analysis
Analyzed Netflix content growth over time using:
- Total Content
- Latest Year Content
- Previous Year Content
- Year-over-Year Growth
- Content Growth Over Time
- Movies vs TV Shows by Year
- Yearly Content Growth %
- Growth insights

Task 5 - Audience & Category Intelligence
Analyzed audience ratings and Netflix content categories using:
- Total Content
- Top Audience Rating
- Total Categories
- Top Content Category
- Content by Audience Rating
- Top 10 Content Categories
- Movies vs TV Shows by Rating
- Category Distribution
- Strategic Insights
- Interactive filters

Key Insights

- TV-MA is the most common audience rating.
- International Movies is the leading content category.
- Movies represent the largest share of Netflix content.
- The United States has the highest content volume.
- Netflix content experienced significant growth after 2000.
